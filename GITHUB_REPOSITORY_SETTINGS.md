## 🔍 How to Apply These Settings

### Via GitHub Web Interface

1. Go to your repository: `https://github.com/adrian207/Audit-Azure`
2. Click the **⚙️ Settings** tab
3. Under **General**:
   - Update the **Description** field
   - Update the **Website** field
4. Click on the **About** ⚙️ gear icon (top right of repository home):
   - Edit description
   - Add website
   - Add topics/tags (type and press Enter for each)
5. Save changes
